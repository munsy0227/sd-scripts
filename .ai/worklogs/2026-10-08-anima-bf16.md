# 2026-10-08 Anima BF16 autocast fix

## Change

The caller's BF16 autocast was disabled in Block and FinalLayer AdaLN when
`use_fp32=False`. With AdaLN-LoRA, timestep features remain FP32 while loaded
weights may be BF16, causing a dtype mismatch before any external adapter.

Both contexts now use `nullcontext()` in this case. The existing FP32 autocast
remains enabled for `use_fp32=True`, preserving the CUDA FP16 path. RMSNorm,
timestep precision, parameter schema/dtype, API and checkpoint format are unchanged.

The fork's local main was synchronized to upstream
`690ea7f96c23182352ec63def76d431c6120bd2f` after verifying a complete bundle of
all prior refs and history outside this repository. Old bucket `aa763e0` and
merge `c9224ba` are not ancestors of the new main. Existing `.venv` and user
files were preserved. Remote publication uses expected-SHA updates. The initial
remote reset was rejected by branch protection; the old work branch was deleted
through GitHub, preserving its merged PR record.

## Verification

Linux / RTX 4070, Python 3.12.15, PyTorch 2.13.0+cu130, Transformers 5.17.0.
CPU threads were 1. Dependencies were isolated; existing `.venv` was not changed.

- `pytest tests/test_anima_precision.py`: before patch, 18 failed / 12 passed,
  including the real model's CPU/CUDA BF16 failure; after patch, all 30 passed.
  Tests exercise Block/FinalLayer, both AdaLN structures, CPU FP32/BF16 and CUDA
  FP32/FP16/BF16, finite forward/backward, caller autocast state, FP32 timestep,
  unchanged parameter identity/schema, and exact gradient checkpointing parity.
- Original-versus-patched actual model: CPU FP32, CUDA FP32/FP16, both AdaLN
  structures; all six outputs and gradients were bitwise identical.
- Related offloading/sampling/warning/cv2 tests: 78 passed, 6 hardware skips.
- Training-script offline help: Anima and standard train_network passed.
- LyCORIS real Anima integration: 28 reduced-width blocks and 448 diffusion-only
  full-matrix LoKR/DoRA adapters. Twelve CPU/CUDA FP32/BF16 cases with checkpointing
  off/on passed exact initial no-op, 448 finite/nonzero scalar gradients, SGD
  output change, preserved base weights and exact native checkpoint reconstruction.
- Existing LyCORIS CPU selection: 150 passed / 2 optional skips. Three dedicated
  CUDA tests passed. Direct requirements match upstream, and metadata traversal
  found no conflicts across 86 transitive dependency sets. Ruff and diff checks passed.

BF16 portable export is separately measured: max output absolute error
0.0399169922; four CPU cases exceed the unchanged `atol=rtol=0.03` reference.
CUDA BF16 cases meet that combined reference, with maximum absolute error
0.0390625. Native reconstruction remains exact. Portable numerical accuracy is
not claimed fixed. Extra high-rank FP16 checkpoint tests found alpha overflow at
rank 100000; that independent LyCORIS limitation was recorded and not changed.

No pretrained full checkpoint, dataset/VAE/training loop, long run, Windows or
MPS validation was performed. Detailed integration results are in LyCORIS
`.ai/worklogs/2026-10-08-anima-bf16-fork.md` and retained local validation logs.
